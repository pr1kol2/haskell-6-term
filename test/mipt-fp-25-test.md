**3.** (1) В модуле `Data.List` определена функция `inits`, такая что для всех значений `f` и `u` соответствующих типов верно равенство

**4.** (1) Используя `mapM`, реализуйте функцию `lower`, по входному списку `[a1,. . . ak] :: [Int]` неотрицательных чисел выдающую список всевозможных списков вида `[b1, ..., bk]`, где `0<= bi <= ai` при всех `i`. **5.** (2) Имеется $n$ шаров и $n$ урн, причем $n \geq 3$. Каждый шар равновозможно и независимо от других попадает в одну из урн. Реализуйте вероятностный эксперимент для оценки вероятности $p_{n}$ того, что ровно две урны останутся пустыми. Вот некоторые теоретические значения: $p_{3}=\frac{1}{9}, p_{4}=\frac{21}{64}, p_{5}=\frac{12}{25}, p_{6}=\frac{325}{648}, p_{7}=\frac{7200}{16807}$, $p_{100}<10^{-35}$.

**6.** (2) Заполните пропуски в программе и докажите, что с вашими заполнениями выполняются законы монад:

```hs
import Control.Monad
data Dup a = Dup a a
instance Functor Dup where
  fmap = liftM
instance Applicative Dup where
  pure = _
  (<*>) = ap
instance Monad Dup where
  (>>=) = _
```

Напомним, у монад есть три закона:

- a) pure нейтральна слева: `pure x >>= h = h x`;
- б) pure нейтральна справа: `m >>= pure = m`;
- в) связывание ассоциативно: `m >>= g >>= h = m >>= (\x -> g x >>= h)`.
